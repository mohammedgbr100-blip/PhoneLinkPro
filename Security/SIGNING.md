# التوقيع الرقمي — PhoneLink Pro

<div dir="rtl">

## لماذا التوقيع؟
عند تنزيل المستخدمين لـ `PhoneLinkPro-Setup.exe` غير موقّع، يظهر تحذير **Windows SmartScreen**
(«Windows protected your PC»). التوقيع الرقمي (Authenticode) يُثبت هويتك كناشر ويزيل/يقلّل التحذير،
ويمنع العبث بالملف بعد التوقيع.

## الأدوات جاهزة
- **`sign.bat`** — يوقّع `PhoneLinkPro.exe` والمثبّت بـ SHA-256 وختم زمني RFC-3161 موثوق.
  (تم اختبار الخط بنجاح: التوقيع + الختم الزمني يعملان.)
- **`make-test-cert.bat`** — ينشئ شهادة تجريبية ذاتية لاختبار الخط فقط (لا تزيل التحذير).

## أنواع الشهادات (للإصدار الحقيقي)
| النوع | التكلفة التقريبية | التأثير على SmartScreen |
|---|---|---|
| **OV** (Organization/Individual Validation) | ~60–400$ / سنة | يبني السمعة تدريجياً مع عدد التنزيلات |
| **EV** (Extended Validation) | ~300$+ / سنة (توكن أجهزة) | **ثقة فورية** في SmartScreen |

**مزوّدون:** DigiCert · Sectigo · SSL.com · **Certum** (رخيص للأفراد، مناسب لك كمطوّر فردي).
> للأفراد بميزانية محدودة: شهادة OV من Certum خيار جيد للبداية. لثقة فورية بلا انتظار سمعة: EV.

## خطوات التوقيع
1. احصل على الشهادة (ملف `.pfx` + كلمة مرور، أو توكن EV).
2. افتح `Security\sign.bat` وعدّل في الأعلى:
   ```
   set "CERT=C:\path\to\your-cert.pfx"
   set "PASS=your-password"
   ```
   (اترك `CERT` فارغاً لاختيار أفضل شهادة من مخزن ويندوز تلقائياً — مفيد مع توكن EV.)
3. الترتيب الموصى به:
   ```
   publish.bat
   Security\obfuscate.bat        (اختياري)
   Security\sign.bat             ← يوقّع PhoneLinkPro.exe
   installer\build-installer.bat ← يحزم الـ exe الموقّع
   Security\sign.bat             ← يوقّع المثبّت أيضاً
   ```
4. تحقّق: الأمر `signtool verify /pa الملف` — مع شهادة CA حقيقية تكون النتيجة موثوقة بالكامل.

## ملاحظات
- **الختم الزمني ضروري**: يُبقي التوقيع صالحاً حتى بعد انتهاء صلاحية الشهادة. (مضمّن في `sign.bat`.)
- الشهادة الذاتية (`make-test-cert.bat`) **لن** تزيل تحذير SmartScreen — لاختبار الخط فقط.
- وقّع **بعد** التعتيم (obfuscate)، لأن أي تعديل على الملف يُبطل التوقيع.
