# تعتيم الشيفرة (Obfuscation) — النتيجة والتوصية

<div dir="rtl">

## ما تم تطبيقه فعلياً (يعمل ✅)
حماية **على مستوى الشيفرة**، مفعّلة في نسخة الإصدار:
- `Services\SecurityGuard.cs` — كشف المنقّحات (debugger) وأدوات التحليل (dnSpy / ILSpy / dotPeek / x64dbg / OllyDbg / WinDbg / Cheat Engine) وإنهاء البرنامج فوراً + فحص دوري.
- بناء **Release مُحسّن، بدون ملفات PDB** (لا رموز تصحيح).
- **أسماء عمليات محايدة** (المحرّك = `PhoneLink.Engine.exe` / `PhoneLink.Bridge.exe`).

## تعتيم IL عبر ConfuserEx — جُرِّب وفشل (مُوثّق)
جرّبنا **ConfuserEx2 v1.6.0** (أحدث إصدار متاح) على `PhoneLinkPro.dll`:
- المجموعة الكاملة (constants + ctrl flow + anti-debug/dump) → التطبيق **يتعطّل عند الإقلاع**
  باستثناء CLR (كود `0xE0434352`).
- حتى **تشفير النصوص وحده** (`constants`) → نفس التعطّل.

**السبب:** ConfuserEx v1.6 صدر عام 2020 (أداة .NET Framework) **قبل .NET 9**، ويحقن مُهيّئ وحدة
وقت تشغيل غير متوافق مع CoreCLR/.NET 9 المستقل + BAML الخاص بـ WPF. لذلك **أُزيل من المشروع**
لأنه يكسر التطبيق.

## التوصية لتعتيم IL حقيقي (إن رغبت لاحقاً)
استخدم مُعتِّماً حديثاً يدعم **.NET 9 + WPF** صراحةً (يتعامل مع BAML وCoreCLR بشكل صحيح):
| الأداة | ملاحظات |
|---|---|
| **Eazfuscator.NET** | تجاري، دعم ممتاز لـ WPF/.NET الحديث |
| **.NET Reactor** | تجاري، تعتيم + تشفير + حماية ترخيص مدمجة |
| **Babel Obfuscator** | تجاري، يدعم .NET الحديث |
| **Dotfuscator (CE/Pro)** | نسخة مجتمعية محدودة + نسخة احترافية |

بعد التعتيم بأيٍّ منها: **شغّل التطبيق وتأكّد أنه يعمل**، ثم وقّعه (`sign.bat`)، ثم ابنِ المثبّت.

## ⚠️ القاعدة الذهبية للميزات المدفوعة
أي حماية على جهاز المستخدم (تعتيم/تشفير) **قابلة للكسر**. اجعل **التحقق من الترخيص وتفعيل
الميزات المدفوعة على خادم (Server-side)**:
- مفاتيح ترخيص مربوطة بحساب/جهاز، يُتحقّق منها عبر API عند التشغيل والتفعيل.
- نفّذ/فعّل الجزء الحسّاس من الميزة على الخادم لا في التطبيق.
- عندها لا يكفي كسر التطبيق محلياً لفتح الميزة؛ التعتيم يرفع الحاجز فقط.
