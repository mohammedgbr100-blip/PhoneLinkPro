================================================================================
Verified (2026-11-13):

  (a) BUILD PROVENANCE. The official scrcpy-win64-v3.3.4.zip downloaded from
      https://github.com/Genymobile/scrcpy/releases/tag/v3.3.4 has SHA-256
      d8a155b7c180b7ca4cdadd40712b8750b63f3aab48cb5b8a2a39ac2d0d4c5d38, which
      matches the release's SHA256SUMS.txt; that file carries a good OpenPGP
      signature from Romain Vimont (primary key fingerprint
      4569 58E8 5A18 5DD5 C2D1 E4E8 0C82 2B29 8461 FA03). Every file listed in
      this notice matches, byte for byte, the corresponding file of that
      official package (engine integrity manifest, Resources/engine.manifest).

  (b) FFmpeg BUILD CONFIGURATION. Read from the binaries; see section 3.

  (c) NOTICE FILES. scrcpy ships no NOTICE file (only LICENSE). The AOSP adb
      NOTICE attribution is reproduced in section 2.

Still open — to be completed before distributing the binaries (installer):

  (d) STATICALLY LINKED CODE INSIDE adb.exe. Google's adb.exe statically links
      further third-party libraries. Strings in the binary identify at least:
      BoringSSL (OpenSSL/SSLeay/ISC-style licenses), Protocol Buffers
      (BSD-3-Clause), libusb including its libusbK/WinUSB backend (LGPL-2.1+),
      Open Screen (BSD-3-Clause) with Abseil (Apache-2.0), mDNSResponder client
      (dnssd_clientstub; Apache-2.0 / BSD-3-Clause), LZ4 (BSD-2-Clause),
      Zstandard (BSD-3-Clause), Brotli (MIT), zlib 1.3.0.1 (zlib License), the
      AOSP base library libbase (Apache-2.0), the LLVM C++ runtime (libc++,
      libc++abi, libunwind; Apache-2.0 WITH LLVM-exception) and the mingw-w64
      runtime. Google lists their full notices in the NOTICE.txt file of the
      platform-tools package; that file is not part of the scrcpy package and
      is not yet reproduced here.
      Exact source package: platform-tools_r36.0.0-win.zip from
      https://dl.google.com/android/repository/ (7138784 bytes, SHA-256
      12c2841f354e92a0eb2fd7bf6f0f9bf8538abce7bd6b060ac8349d6f6a61107c, the
      value pinned by scrcpy v3.3.4); adb reports "Version 36.0.0-13206524".
      Security/fetch-platform-tools-notice.ps1 copies that package's NOTICE.txt,
      unmodified, to Licenses/platform-tools-NOTICE.txt after proving the
      package's adb.exe, AdbWinApi.dll and AdbWinUsbApi.dll are byte-identical
      to the shipped engine files. Until that file exists, release.ps1 marks
      every build NOT FOR PUBLIC RELEASE.
      libusb is LGPL-2.1+ and is statically linked into adb.exe. Its source,
      and the AOSP source of adb needed to relink it, are available from
      https://github.com/libusb/libusb and
      https://android.googlesource.com/platform/packages/modules/adb/ ; whether
      pointing to those sources meets LGPL-2.1 section 6 for this binary has not
      been reviewed by counsel.

  (e) ANDROID PLATFORM-TOOLS TERMS. adb is Apache-2.0 licensed as part of the
      Android Open Source Project, but the bundled copy is Google's prebuilt
      binary from the platform-tools download, which Google distributes under
      the Android SDK License Agreement. Its section 3.4 forbids
      redistributing the SDK except as required by third-party licenses, and
      section 3.5 says components under an open-source license are governed
      solely by that license. Whether section 3.5 covers redistributing this
      prebuilt adb.exe has not been reviewed by counsel.
